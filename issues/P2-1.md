# P2-1 — `Validatable::validate()` calls `$this->toArray()`, which comes from …

## Finding / 问题

- EN: `Validatable::validate()` calls `$this->toArray()`, which comes from `DataAccess`, but the trait declares `validationRules()` abstract and not `toArray()`. A class using `Validatable` alone compiles fine and throws `Call to undefined method ...::toArray()` only when validate() runs.
- 中文: Validatable::validate() 调用 $this->toArray()，它来自 DataAccess，但 trait 只把 validationRules() 声明为 abstract，漏了 toArray()。单独 use Validatable 的类能正常编译，直到运行 validate() 才抛 Call to undefined method ...::toArray()。
- Where / 位置: `src/Validatable.php:95,71`
- Verification / 验证: reproduced / 已实证
